## 프로젝트 개요
- 목적 
  해커톤 공모 프로젝트를 통해 보안 도메인 기반 AI Chat 서비스의 UI/UX 설계 및 프론트엔드 구현 경험을 정리하기 위함
- 사용 언어
  HTML, CSS, JavaScript (파일 분리 구조)
- 주요 특징  
  - 단기간 내 구현 가능한 범위에서의 **Chat 서비스 UI/UX 설계**
  - 웰컴 메시지 및 **퀵 액션 버튼 기반 대화 시작 구조**
  - Chat 서비스에 적합한 **JavaScript 기반 간단한 응답 로직 구현**
  - 메시지 타이핑 효과 및 사용자/봇 구분 UI 처리
  - 반응형 레이아웃 및 사이드바 접힘/확장 인터랙션
  - 공모 프로젝트 특성을 고려한 **최소한의 데이터 구성**

보안 및 정책상의 이유로 실제 데이터는 사용하지 않고 샘플 텍스트 중심으로 구성되어 있습니다.
로고 및 일부 시각 요소 또한 포트폴리오 목적에 맞게 재구성되었습니다. 본 프로젝트는 기능의 완성도보다는 디자인, 퍼블리싱, 그리고 Chat UI에 적합한 JavaScript 인터랙션 구현에 중점을 두고 있습니다.
